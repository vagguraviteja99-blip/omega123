# Code of Conduct

## Our standard

We want this project to be welcoming and useful for everyone. Be respectful, constructive, and patient.

## Unacceptable behavior

Harassment, discrimination, threats, personal attacks, doxxing, and deliberately disruptive behavior are not welcome.

## Enforcement

Report serious concerns privately to the repository maintainer through the contact method listed in the repository. Reports will be reviewed fairly and confidentially when possible.
