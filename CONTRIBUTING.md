# Contributing

Thanks for your interest in improving these projects.

## Before opening an issue

- Search existing issues first.
- Use a clear title.
- Include your Windows version, Android device or AVD, and the exact command used.
- Remove passwords, tokens, private keys, and personal data from logs.

## Pull requests

1. Explain the problem and the proposed change.
2. Keep changes focused.
3. Update documentation when behavior changes.
4. Test PowerShell scripts on a supported Windows system.
5. Include relevant screenshots or logs when useful.
